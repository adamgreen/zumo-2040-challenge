# The Zumo 2040 Challenge!
## Overview
This is meant as a quick low friction way to get into Mini Sumo:
* No need to design custom mechanical or electronics.
* Use an existing Mini Sumo robot kit instead.
* Concentrate on Mini Sumo strategy, algorithms, and code instead.

## Pololu Zumo 2040 Robot
![Zumo 2040 Robot](pololu-zumo-2040.png)

The [Pololu Zumo 2040 Robot](https://www.pololu.com/category/308/zumo-2040-robot) will be used for this challenge. Either of the following versions can be used by challengers depending on whether they want to build the bot themselves or not:
* **Kit Version**
  * 1 x [Zumo 2040 Robot Kit (No Motors)](https://www.pololu.com/product/5010)
  * 2 x [75:1 Micro Metal Gearmotor HP 6V with Extended Motor Shaft](https://www.pololu.com/product/2215)
* **Preassembled Version**
  * 1 x [Zumo 2040 Robot (Assembled with 75:1 HP Motors)](https://www.pololu.com/product/5012)

## Rules
* Adhere to the **Autonomous 500g Mini Sumo** variant of the [SRS Sumo Rules](https://robothon.org/rules-sumo/).
* No changes to the stock **Zumo 2040 Robot** are currently permitted.
  * No mechanical modifications or additions allowed.
  * No electronic modifications or additions allowed.
* Challengers are encouraged to modify/improve/replace the software as much as possible!!

## Other Goals
* Increase interest in Mini Sumo.
* Compete with challenge robots in the [Robothon & More](https://robothon.org/summer-2026-robothon-event/) event on **August 22nd, 2026** in the **Capital Hill** region of Seattle, WA.
* Could allow for remote robot competitions:
  * Contestants would submit their custom **.uf2** firmware images to event organizers.
  * Each firmware image submitted would be turned into 2 contestants:
    * FirmwareFoo-**A** and FirmwareFoo-**B**
    * The contest would be run with only two robots:
      * **Robot-A** and **Robot-B**
    * The ***-A** version would always run on **Robot-A**.
    * The ***-B** version would always run on **Robot-B**.
  * These 2 versions would be used in an attempt to reduce the influence of one physical robot on the final winner since each contestant gets to compete as both physical robots.
  * **Robot-A** and **Robot-B** used for the competition could be pre-assembled versions purchased from Pololu to reduce differences in the bots since they were hopefully built by the same person who has built many of them in the past resulting in a consistent flow to their construction process.
  * In an ideal situation where one contestant's firmware is much better than the others, it would be their **-A** and **-B** versions that ended up competing in the final.
  * To obtain unique 1st, 2nd, and 3rd place finishers, only a firmware's best result would be kept and the rest discarded (ie. both the **-A** and **-B** variants cannot end up in the top 3).
* Present a path for at least one of the contestants to get into the design of their own custom Mini Sumo robots that would be competitive in existing Mini Sumo contests such as at the SRS Robothon events.
